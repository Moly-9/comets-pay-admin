## 基线验证

- `npm run build` 通过 TypeScript 检查和 Vite 生产构建。
- `deploy/server.mjs` 通过 Node 语法检查。
- `deploy/com.muse-pay-8771.plist` 通过 `plutil -lint`。
- 本地源码中的服务入口和 LaunchDaemon plist 与当前远端快照哈希一致。
- 本地构建 CSS 与当前远端快照哈希一致。
- 本地构建的主 JS 和 Invoice 模块与当前远端快照哈希不同，说明源码包包含快照
  之后的功能变化；未经单独验收，不得将其直接视为当前远端发布包。
- 本地 Vite 开发和预览服务仅监听 `127.0.0.1`，不向局域网开放。
- 依赖审计仍报告 Vite 5 工具链相关风险；完整修复需要单独评估 Vite 大版本升级。
  生产部署只发布静态 `dist`，不运行 Vite 开发服务器。

## 边界

该工程仍是纯前端交互原型，没有真实后端、数据库、服务端鉴权、飞书回调或支付
渠道连接。任何部署仍必须遵循仓库根目录的备份、验证和显式授权要求。
